# Module 07 — Extensions

## Goal

Package an agreed team workflow so new contributors can use it without rebuilding it from memory.

## Practice

Create one folder that contains:

- the workflow instructions;
- example input and expected output;
- a small configuration file for names or paths that differ by project;
- a changelog documenting why the workflow changed.

Version the package with the repository. Treat it as a product: a short install path, a stable interface, and clear documentation matter more than a long feature list.

## Check

Ask a teammate to install it without help. Improve the first point where they pause.
