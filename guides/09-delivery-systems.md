# Module 09 — Delivery systems

## Goal

Combine context, roles, checks, and checkpoints into one transparent path from request to delivery.

## Practice

Map a small feature workflow:

```text
Request → explore → plan approval → implement → targeted checks → review → delivery note
```

For each arrow, record the input, output, owner, and stop condition. Begin with one real type of request, such as a bug fix, rather than trying to automate every project activity.

## Check

Someone should be able to explain why a change was made by reading the outputs of this workflow. If they cannot, add an explicit decision note.

## Next step

Improve the commands used to inspect, test, and report on this workflow.
