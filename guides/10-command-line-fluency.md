# Module 10 — Command-line fluency

## Goal

Use small, observable commands to move quickly without losing control of the work.

## Practice

Build a personal command checklist:

- list and search files before opening them;
- inspect repository status before editing;
- run the narrowest relevant test first;
- inspect the diff before committing;
- keep a short record of commands that caused a meaningful change.

Use commands that show their scope. A command you can explain, rerun, and review is usually safer than one large command that hides several actions.

## Check

For your next change, write a one-sentence purpose beside each non-obvious command in the pull request or delivery note.
